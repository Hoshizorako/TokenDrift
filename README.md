# TokenDrift

Watches and reports on network traffic patterns and anomalies in distributed systems for network administrators and security teams.

TokenDrift is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/TokenDrift.git`
2. `cd TokenDrift`
3. Install in editable mode: `pip install -e .`

## Configuration

TokenDrift is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
